# Result M3.25 — Close `doctor` Host-Probe DI Gap, `crun` Host-vs-Rootfs Split, Rule 3 Contract, Typed `WorldId` Selector, Phase-2 GC Ports, and `STP v1` CBOR Wire Framing (`ARCHITECTURE.md`, `ADR-0002`, `ADR-0005`, `ADR-0006`, `ADR-0008`, `ADR-0009`, `ADR-0010`)

## Architectural Rulings & Rationale

### 1. `slipfork doctor` Diagnostic Seam (`HostProbe` + `SubvolumeDriver`, Single `EngineError` & Hint Owners, Zero Host `crun` Probe)

- **Ruling:** Define `pub trait HostProbe: Send + Sync` (`probe_userns`, `probe_netns` -> two-variant `HostCheckOutcome { Ok, Failed { detail, hint } }` — zero unreachable `Skipped`), `NetnsCheck { Executed(HostCheckOutcome), Skipped }` (`Skipped` synthesized solely by `doctor::run`), `DoctorReport`, and `doctor::run(&dyn SubvolumeDriver, &dyn HostProbe, state_dir, uid, gid) -> Result<DoctorReport, EngineError>` in `#![forbid(unsafe_code)]` `crates/slipfork::doctor` (`M3.15`), wired solely in `crates/slipfork/src/main.rs` over `KernelBtrfsDriver` + `OsHostProbe` (never in `slipforkd` boot), with **zero host `crun` probe** (`ADR-0010` §4 sole home).
- **Single error & remediation-hint owners (`ARCHITECTURE.md` §3.3, `ADR-0010` §4):**
  - `pub enum WorldRef { World(WorldId), SeedSlot(String), Handle(WorldHandle) }` and `pub enum EngineError` are declared once in `ARCHITECTURE.md` §3.3 (`BtrfsRequired`, `SubvolumeDestroyDenied`, `Ioctl { op, path, errno }`, `UsernsDenied { detail, hint }`, `ServiceReadinessFailed`, plus the domain variants carrying typed `world: WorldRef` — zero stringly `world: String`).
  - `pub const BTRFS_MOUNT_HINT: &'static str` in `crates/slipfork-engine::btrfs` (`"sudo mount -o user_subvol_rm_allowed,noatime /dev/<device> <state_dir>"`) is shared by `EngineError::{BtrfsRequired, SubvolumeDestroyDenied}` and `doctor` (`DoctorReport.fixes` + `subvolume_ioctl.hint`).
  - `pub fn userns_remediation_hint(bin_dir: &Path) -> String` in `#![forbid(unsafe_code)]` `crates/slipfork-engine` (`M3.13` target state, zero `current_exe()` call) is shared by `BtrfsEngine` (`EngineError::UsernsDenied`, passing `world_init_bin` parent, `M3.13`) and `OsHostProbe::probe_userns` (`current_exe()` parent, `M3.15`).
  - Static `crun` is a world-rootfs asset (`ADR-0009` §1 is the single normative home owning `<state_dir>/cache/runtime/crun-<ver>-<arch>-<sha12>.bin`, with composition-root `--crun <path>` / `--world-init <path>` declared in `ARCHITECTURE.md` §1); `ADR-0010` §4 is the single normative home stating `doctor` performs no host `crun` probe.
- **Exact split between `ensure_supported`, `probe`, and `destroy_subvolume` (`ADR-0010` §4 + Consequences):**
  - `SubvolumeDriver::ensure_supported(&self, path: &Path) -> Result<(), EngineError>` (`slipforkd` boot): **magic-only** (`statfs(path).f_type == BTRFS_SUPER_MAGIC` -> `EngineError::BtrfsRequired` on mismatch; proves neither `user_subvol_rm_allowed` nor `noatime`).
  - `SubvolumeDriver::probe(&self, path: &Path) -> Result<BtrfsProbeReport, EngineError>` (`slipfork doctor` via `btrfs::probe_with`): returns `Ok(BtrfsProbeReport { btrfs_super_magic: false, user_subvol_rm_allowed: None, .. })` on non-Btrfs hosts (creating nothing; `doctor` never receives `BtrfsRequired`), runs the live scratch round-trip under `<state_dir>/.doctor-probe-<pid>` iff `btrfs_super_magic == true`, and best-effort clears RO / destroys any scratch snapshot and subvolume and removes `.doctor-probe-<pid>` on every intermediate error path before returning.
  - `SubvolumeDriver::destroy_subvolume`: maps `EPERM` on Btrfs to `EngineError::SubvolumeDestroyDenied { path, errno, mount_hint: BTRFS_MOUNT_HINT }` and non-`EPERM` failures to `EngineError::Ioctl { op, path, errno }`.
  - `noatime: bool` on `BtrfsProbeReport` is **advisory only**: excluded from both `DoctorReport.ok` and `DoctorReport.fixes` so `fixes.is_empty() <=> ok == true` holds unconditionally, and `DoctorReport.fixes` uses the fixed deterministic emission order **`btrfs` -> `unshare_userns` -> `netns`** (`ADR-0010` §4 sole home).
  - `--json` projection (`ADR-0010` §4): flattens `btrfs.{state_dir,probed_path,fstype,btrfs_super_magic,noatime}` to top-level keys, renames `btrfs.user_subvol_rm_allowed` to top-level `"subvolume_ioctl"`, and sources both `subvolume_ioctl.hint` (on `Some(Err(_))`) and the Btrfs entry in `fixes` from `BTRFS_MOUNT_HINT`.

### 2. Typed `WorldId`, Single Selector Parser & Shared `WorldSelector` (`ADR-0005` §3, `ADR-0008` §4, `ARCHITECTURE.md` §3.4)

- **Ruling:** Define `pub struct WorldId` (`fmt::Display` + `std::str::FromStr` + manual JSON-string `Serialize`/`Deserialize` — never derived struct-object serde) in `crates/slipfork-world` as the **single owner** of world-id formatting and parsing (`ADR-0005` §3 is the sole normative grammar home; `ARCHITECTURE.md` §3.4 points to `ADR-0005` §3):
  1. **Bijection over `Canonical | UserFork`, non-selector `<project>#test-<slot>` diagnostics, & `TestSlot` wire exclusion:** `Display` formats `<project>` (`Canonical`), `<project>:<fork>` (`UserFork`), and non-selector `<project>#test-<slot>` (`TestSlot`, diagnostics-only for `WorldRef::World` and `RoutedWorld`); `TestSlot` pool worlds are owned internally by `crates/slipfork-test`, excluded from `DaemonControl::list` and `PruneReport.worlds`, and refused by `WorldId::serialize` (`ser::Error::custom`), forming an exact round-trip bijection over `Canonical | UserFork` while `#` ensures no CLI screen, stderr diagnostic, or wire frame ever emits a selector spelling the CLI rejects.
  2. **Single `':'`-splitting parser (`WorldId::from_str` -> `WorldId::parse_selector` -> `project::resolve_world_selector`):** `WorldId::from_str` trims ASCII whitespace once (`let s = raw.trim();`; empty or embedded whitespace fails closed), owns the sole `':'` split (`<project>:<fork>` -> `UserFork`, including `<project>:<project>` -> `UserFork(<project>)`), and parses bare `<project>` -> `Canonical`. `WorldId::parse_selector(raw, current_project)` trims once (`s = raw.trim()`), delegates `s.contains(':') || s == current_project.as_str()` directly to `WorldId::from_str` + `id.project() == current_project` (`WorldError::CrossProjectWorld` on mismatch), and otherwise validates bare `<fork>` (`validate_fork_name(s, &[])`) -> `UserFork(<fork>)` in `current_project`.
  3. **Single `WorldSelector` carrier across `--world` and `drop`:** `WorldSelector { pub cwd: PathBuf, pub world: Option<WorldId> }` (`ARCHITECTURE.md` §3.4) is passed directly to `down`, `drop_fork`, `share`, and `unshare` and flattened (`#[serde(flatten)] pub selector: WorldSelector`) into explicitly declared `UpRequest`, `LogsRequest`, `ExecTargetRequest`, `HookRunRequest`, and `ForwardRequest` (zero duplicate `DropForkRequest`), routing `slipfork drop [<world>]` / `--world <world>` through the **exact same** `project::resolve_world_selector` / `WorldId::parse_selector` (`DaemonService::drop_fork` refuses `Canonical` naming `slipfork down`), while `slipfork fork <fork>` (`ForkRequest`) trims ASCII whitespace and requires a new bare `<fork>` (`!= repo.project`).
  4. **End-to-end typed `PruneReport` & `WorldRef`:** `PruneReport { dry_run, worlds: Vec<WorldId>, snapshots: Vec<SnapshotId>, artifacts: Vec<String>, rootfs_digests: Vec<RootfsDigest>, oci_digests: Vec<String>, reclaim_bytes: u64 }` is declared once in `ARCHITECTURE.md` §3.4 (`RootfsDigest` serializing bare 64-char lowercase hex at `--json`), `WorldSpec` carries `pub world: WorldId`, and `EngineError` carries typed `WorldRef`.

### 3. `WorldEngine::ensure_base`, Typed `BaseKey::snapshot_id` Retention, Symmetric Phase-2 GC Ports, Rule 3, & Bounded `STP v1` CBOR Framing

- **`WorldEngine::ensure_base` & explicit `BaseKey` + `BaseSeedSpec` (`ADR-0010` §2, `ADR-0002` §1, `ADR-0009` §2, `ARCHITECTURE.md` §§3.2–3.3):** `ADR-0010` §2 is the sole owner of `<project>-base-<base_key_sha12>`, `worlds/seed-<base_key_sha12>`, and `<state_dir>/ctl/seed-<base_key_sha12>` (`ARCHITECTURE.md` §3.3 points to `ADR-0010` §2), `BaseKey { pub project: ProjectSlug, pub sha256: String, pub rootfs_digest: RootfsDigest, pub oci_digests: BTreeSet<String> }` declares `BaseKey::derive`, `sha12`, and `snapshot_id(&self) -> SnapshotId` (sole `BaseKey -> SnapshotId` constructor), `ARCHITECTURE.md` §3.2 owns the 4-method `SeedDumpStore` (`lookup`, `write_from`, `discard`, `materialize` -> `.pgcustom`; cited by `ADR-0008` §2), and `WorldEngine::ensure_base(&self, seed: &BaseSeedSpec) -> Result<(), EngineError>` sits directly on `trait WorldEngine` (`BtrfsEngine` sole production impl, so `DaemonService` holds only `Arc<dyn WorldEngine>` and never concrete `BtrfsEngine`, while `WorldSpec` carries no seed payload and `WorldSpec.state_subdirs` is authored once by `slipforkd`).
- **Single retention owner (`DaemonService::prune`) & symmetric Phase-2 (`M3.2`) GC ports (`ARCHITECTURE.md` §3.3/§3.6, `ADR-0010` §3, `ADR-0009` §3, `ADR-0002` §1):** Phase 1 `slipfork prune` prints an explicit retention line when `PruneReport.snapshots` is empty; in Phase 2 (`M3.2` / `M3.2.13`), `DaemonService::prune` in `slipforkd` is the **sole retention owner** — retaining `BaseKey` on every surviving attached live world record, in-flight `BaseSeedSpec` / `M3.2` `WorldPool` lease, and active `DigestCache` lineage root, inserting typed `base_key.snapshot_id()` into `WorldEngine::prune_snapshots(&BTreeSet<SnapshotId>, dry_run)`'s keep-set (alongside surviving `WorldSpec.snapshot` and `DigestCache` stage/fixture `SnapshotId`s so retained sealed bases are protected and superseded bases are collected), populating `CacheKeepSet` for `BaseImageBuilder::prune_cache(&CacheKeepSet, dry_run)` from surviving `WorldSpec.rootfs` + retained `BaseKey`s (`<state_dir>/cache/runtime/` never collected), and passing referenced artifact digests to `ArtifactStore::prune_artifacts(&BTreeSet<String>, dry_run)`.
- **`ADR-0009` §3 Rule 3 & Bounded `STP v1` CBOR (`ADR-0006` §3):** Static pre-boot Rule 3 checks root-only privilege-drop entrypoints (`BaseImageError::RootAtRuntimeEntrypoint`) only (boot-time `EROFS`/`EACCES` is the sole runtime file-access enforcement), and `ADR-0006` §3 is the sole normative home specifying 4-byte BE length-prefixed (`u32` in `1..=MAX_STP_FRAME_BYTES`, `MAX_STP_FRAME_BYTES = 16 MiB`) **RFC 8949 CBOR** on `SLIPFORK_PROTOCOL_FD` (`ARCHITECTURE.md` §1/§2/§3.6 keep `STP v1 (ADR-0006 §3)` pointers only).
