# Goal

Delete dead `0.1.0` cargo surface, obsolete meta-linters and the guard scripts they feed, leaving one honest `make check` gate. No source refactor of live code in this slice.

# Context

- **`crates/slipfork-dag` is LIVE — do NOT delete the crate.** `slipfork dag` was removed for `0.1.0`, but the daemon composition root still consumes the resource-plan types: `crates/slipfork/Cargo.toml:21` (path dep), `crates/slipfork/src/daemon/types.rs:3` (`DumpPolicy, ResourcePlan`), `crates/slipfork/src/daemon/resolve.rs:11` (`DumpPolicy, ResourceMode, ResourcePlan, ResourceStrategy, ResourcesSpec`), `crates/slipfork/src/daemon/base.rs:4` and `daemon/postgres.rs:12` (`PgSeed, ResourcePlan`), `daemon/ospp_supervisor.rs:13` (`ResourcePlan, ResourceStrategy`). Keep `crates/slipfork-dag/src/lib.rs` (490 LOC) + `src/resources.rs` (630 LOC). Delete `crates/slipfork-dag/src/fs.rs` (~154 LOC) and any `lib.rs` re-export/scheduling helper with zero remaining callers (verify with `cargo clippy -p slipfork --all-targets -- -D warnings` + `grep -rn 'slipfork_dag::' crates`). Trim `crates/slipfork-dag/tests/critical_dag.rs` (785 LOC) to the surviving `ResourcePlan`/`DumpPolicy` algorithms only; its full consolidation lands in M3.35.3.
- **Delete `tools/critical_guard.py`** (85-line `--base/--node/--repo/--report` prefix guard; the real protected gate is `make rs-test-live` + `tools/do_vm.py test`). Delete every reference: `AGENTS.md` Law 2 ("guarded by `tools/critical_guard.py`"), the Repository Safety bullets, and the `tools/` row of the "Where Things Are" table; `ARCHITECTURE.md` compliance/testing mentions; `.opencode/agents/*.md` and `.opencode/skills/{testing,git-workflow}/SKILL.md`.
- **Delete `tools/rs_test_list.py` + `tools/tests/test_rs_test_list.py`**: its only consumer is the `Makefile` `rs-test` line `uv run --no-project tools/rs_test_list.py --world-booting $(RS_LIVE_SUITES)`. Replace with an explicit `cargo test -p <crate> --test e2e_*` list (M3.35.3 finalizes names; keep both targets compiling now by listing today's suite names).
- `tools/check_stub_adapters.py` no longer exists in this tree — verify absence and skip (do not recreate).
- `tools/check_zed_extension.py` (+ `tools/tests/test_check_zed_extension.py`), `tools/guard.py`, `tools/plan.py`, `tools/do_vm.py`, `tools/check_docs_honesty.py` and `tools/tests/{test_tools,test_do_vm,test_run_benchmark}.py` all STAY.
- Remove now-dead `Makefile` prerequisites/usages only; do not rewrite the TMPDIR/CARGO_BUILD_JOBS rationale blocks.
- `Cargo.lock` must be regenerated by a `cargo` command, never hand-edited.
