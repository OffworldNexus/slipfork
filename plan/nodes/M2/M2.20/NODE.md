# Goal

Cut the milestone release: bump the workspace and the `@slipfork/opencode` package to `0.2.0`, prove that no declared dependency stayed unused, and run the full repository gate plus the read-only benchmark check.

# Context

- All crate versions inherit from `[workspace.package]`; the plugin package carries its own version; `zensical.toml` labels the nav with the shipped CLI version.
- `M2.2` performed the dependency wedge and recorded a dependency-to-leaf mapping; this node verifies that every declared dependency is consumed, so the wedge does not silently accumulate cruft.
- `M2.15` made `make bench` read-only, so running it here can be part of the gate without dirtying `docs/research/m1-poc-benchmark.md`.

# Design / Invariants

1. **One version source.** `[workspace.package] version = "0.2.0"`; every crate uses `version.workspace = true`; no crate carries its own literal version. `Cargo.lock` is regenerated by the build, never hand-edited.
2. **Plugin version parity.** `packages/opencode-slipfork/package.json` is `0.2.0` and its lockfile entry follows. The plugin and the CLI must never disagree about the major or minor version.
3. **Docs label.** `zensical.toml` shows `CLI (0.2.0)` so the published site cannot advertise a version that was not released.
4. **Changelog.** `CHANGELOG.md` has exactly one `0.2.0` section, dated, listing additions and removals; no compatibility promises (the workspace is pre-`1.0`).
5. **Unused-dependency audit.** For every dependency listed in each crate manifest, at least one source or test file in that crate references the crate name; the audit mapping is recorded in the node log. A dependency with no consumer is **deleted** from the manifest in this node (never parked for later).
6. **MSRV gate.** `[workspace.package] rust-version = "1.94"` (forced by the pinned `tpmd` git crates) matches every published MSRV claim and the release notes; a stale `1.88` anywhere fails this node.
7. **Full gate.** `make check` (plan, hygiene, Python lint and unit tests, TypeScript tests, Rust fmt, clippy plus rustdoc, Rust tests, docs) and `make bench` (read-only mode) both exit `0`, and the working tree is clean afterwards.

# Acceptance

```bash
# 1. Versions are bumped exactly once.
rg -qF 0.2.0 Cargo.toml
rg -qF 0.2.0 packages/opencode-slipfork/package.json
rg -qF 0.2.0 zensical.toml
rg -qF 0.2.0 CHANGELOG.md
! rg -q "^version = " crates/*/Cargo.toml

# 2. Whole workspace builds and tests.
cargo metadata --no-deps --format-version 1 > /dev/null
cargo build --workspace --all-targets
cargo test --workspace --all-targets

# 3. Read-only benchmark check leaves the tree clean.
make bench
git status --porcelain | (! rg -q .)

# 4. Full repository gate.
make check
```

All commands exit `0`. Adversarial assertions required: the audit removes at least one dependency if any was unused rather than leaving it declared, and `make bench` leaves `docs/research/m1-poc-benchmark.md` untouched.
