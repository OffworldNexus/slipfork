Owned by `strategist`. Workspace version `< 1.0.0` carries **zero backward-compatibility cruft**: one canonical way, immediate deletion of superseded drafts, and mandatory human sign-off at architecture crossroads.

Real measured PoC benchmark (`make bench` / `poc/run_benchmark.py` -> `docs/research/m1-poc-benchmark.md`) against PostgreSQL 18 + XFS `FICLONE` + Linux `netns` + warm Python runner + headless Chromium.<br/>5. **Human validation gate** on M1 design & PoC metrics before M2 implementation starts. |
| **M2** | `0.2.0` | **Single-Origin `.localhost` Edge (`slipforkd`), `OSPP v1` WebSocket + `ResourceStrategy`, Live VCS Worlds & Service CLI** | 1. Single-origin `WorldOrigin = Local { url } \| Shared { url }` & deterministic `<= 31`-byte Tunnel Weaver service-label truncation (`<prefix>-<hash>`) in `crates/slipfork-world`; unprivileged `slipforkd` sole local + shared ingress (`LISTEN_FDS` socket activation with `set_nonblocking(true)` + `--listen` tested via `systemd-socket-activate`, `slipfork daemon unit`), `WorldRegistry`, `shared_hosts` map, and `*.localhost`-scoped `308`/`421` rules (`H-008`).<br/>4. Full `WorldEngine` contract (`freeze_world` stopping `WorldProcess` then `OciContainer` services, unified `spawn_service` over `ServiceRuntime { WorldProcess, OciContainer }`, `exec_in_service` / `service_entry_command`, interactive TTY exec + live-streamed hook output, `dial_world_tcp`, multi-mount `WorldSpec` carrying `WorldRootfs`, redacted `ExecEnv` & `S3Coordinates` `Debug`) on live `ReflinkNetnsEngine`; failed hooks/migrations preserve the world and print 1-line `slipfork hook run`, `slipfork logs`, and `slipfork shell` rescue commands.<br/>5. Interactive dev, debugging & service-access CLI (`slipfork up` / `down`, `shell`, `hook run`, `logs`, `db`, `redis`, `forward`, `share [--stop]`, `list`, `prune`, `secret set`, `auth login`) with mode-scoped `modes.<mode>.components.<id>` supervision, container-scoped `db`/`redis` entry commands, `--host-caches` ABI-gated read-only mounts, `OSPP v1` WebSocket client + local server conformance loop (**OSPP remains optional**: offline worlds boot from `0600` `FileVaultProvider`), `VcsWorkspace` (`GitWorktreeAdapter` `<fork>/wip` + `JjWorkspaceAdapter` + `git-remote-slipfork`), and live `@slipfork/opencode` e2e tests.<br/>6. Ratified `H-009` Option B support hygiene (`incus-engine` omitted from `support/integrations.toml` until user-reachable CLI lands), `slipfork support [--json]`, generated docs matrix, read-only `make check` ceiling + `make support-sync`, non-contaminating `make bench`, and isolated leaf adapters for live `IncusEngine` (importing the same `WorldRootfs` as `slipfork-l0-<digest12>`, **gated on `H-004`**) and `WeavedRegistrar` (**gated on `H-006`**). |
