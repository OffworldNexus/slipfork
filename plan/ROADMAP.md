# Slipfork Roadmap (`plan/ROADMAP.md`)

Owned by `strategist`. Workspace version `< 1.0.0` carries **zero backward-compatibility cruft**: one canonical way, immediate deletion of superseded drafts, and mandatory human sign-off at architecture crossroads.

| ID | Target | Title | Exit Criteria |
|---|---|---|---|
| **M1** | `0.1.0` | **Global Target DX/DI Design & Real CoW PoC** | 1. Zero-vaporware Zensical `0.1.0` docs & `CHANGELOG.md` (`docs/`, `make docs-check` + `check_docs_honesty.py` strict clean) plus accepted M2–M4 target DX blueprint (`docs/design/target-dx.md`) covering single-origin `.localhost` edge, `weaved` leases, `git`/`jj` workspaces, world-owned polyglot stacks, typed coverage, and Blastit orthogonality.<br/>2. Global IoC/DI architecture (`ARCHITECTURE.md` + `ADR-0001..0007`) with upward `direction-challenge` & `missing-input` items (`H-001`..`H-003`, `H-005`, `H-006`, `H-008`) validated and closed in `plan/HUMAN.md`.<br/>3. Working Rust workspace (`slipfork-world`, `slipfork-snow`, `slipfork-dag` with typed `[test]` coverage, origin-classified `per_world` fixtures & embedded `support/integrations.toml`, `slipfork-engine`, `slipfork`) + `@slipfork/opencode` V2 plugin with shared conformance & protected critical suites (`make check` green).<br/>4. Real measured PoC benchmark (`make bench` / `poc/run_benchmark.py` -> `docs/research/m1-poc-benchmark.md`) against PostgreSQL 18 + XFS `FICLONE` + Linux `netns` + warm Python runner + headless Chromium.<br/>5. **Human validation gate** on M1 design & PoC metrics before M2 implementation starts. |
| **M2** | `0.2.0` | **Single-Origin `.localhost` Edge (`slipforkd`), `weaved` Leases, Live VCS Worlds & Support CLI** | 1. Single-origin `WorldOrigin = Local { url } \| Shared { url }` (`crates/slipfork-world`) assigned at world materialization (**OSPP is not a prerequisite for M2**: starts on `FileVaultProvider` `0600` vault + derived `.localhost` origins, where Slipfork's origin always wins over provider `domains::`), `slipforkd` as sole local + shared ingress (`H-008`, `shared_hosts` map + `*.localhost`-scoped `308`/`421` rules), `WorldRegistry`, and `DaemonControl` (`register_world` / `release_world` + `share_world` / `unshare_world`).<br/>2. Interactive local lifecycle CLI (`slipfork up`, `down`, `shell [<fork>]`, `share [--stop] [<fork>]`, `list` printing one URL per world, `prune`, `secret set`) with mode-scoped `modes.<mode>.components.<id>` add/remove/override supervision.<br/>3. `VcsWorkspace` (`GitWorktreeAdapter` scratch-index `<fork>/wip` + `JjWorkspaceAdapter` `@`/`@-` + `git-remote-slipfork`) passing `assert_vcs_workspace_conformance`, plus `slipfork support [--json]`, generated docs table, `git`/CI compliance verifier, read-only `make check` ceiling, and explicit `make support-sync` (**gated on `H-009`** pre-`declared` adapter tier classification, `ADR-0007`).<br/>4. Full `WorldEngine` contract (`freeze_world`, `spawn_service`, `dial_world_tcp`, multi-mount `WorldSpec`, redacted `ExecEnv`): live `ReflinkNetnsEngine` + live `IncusEngine` (**gated on `H-004`**).<br/>5. `WeavedRegistrar` outbound tunnel-lease adapter forwarding to `slipforkd`'s planned static port (**gated on `weaved`'s real IPC spec**, `H-006`, `H-008`), independent later `OsppHttpProvider` (`OSPP v1` client + `slipfork auth login`) leaf, and live `@slipfork/opencode` e2e tests. |
| **M3** | `0.3.0` | **Polyglot Parallel Snapshot-DAG Test Orchestrator (`slipfork test`)** | Universal `RunnerProtocol v1` (`AF_UNIX` NDJSON) over canonical `.slipfork/runs/<run_id>/<slot>/{runner.sock,coverage,output}`, origin-independent vs `per_world = true` fixture execution, rolling pre-warmed CoW world pool (with slot-stable coverage mounts) + shared host `BrowserContext`s over `http://test-<slot>.<project>.localhost`, two-tier `batch` vs `world` scheduling, built-in typed `[test]` coverage (`coverage`, `coverage_report`, `coverage_fail_under` `0..=100`) via `TestAdapter::coverage` (`CoverageDriver`), surviving tool-owned `SLIPFORK_OUTPUT_DIR` for Blastit/Allure/Playwright traces, and `ADR-0007` tier-verified `TestAdapter`s starting with `pytest-slipfork` (Adapter #1 + warm Zygote), `Playwright`/`Vitest`, `PHPUnit`/`Pest`, `cargo nextest`, and `CommandTestAdapter`. |
| **M4** | `0.4.0` | **Remote CI Snapshot/Artifact Cache & Agent Ecosystem** | Content-addressed CI/team snapshot & artifact cache export/import, `llms.txt`, and turnkey agent skills for OpenCode, Claude Code, Codex, and Junie. |
