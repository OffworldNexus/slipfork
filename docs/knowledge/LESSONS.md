# Lessons Learned (`docs/knowledge/LESSONS.md`)

Concise, verified host, kernel, Rust, Python, and OpenCode facts. Append 1–2 lines whenever you discover a non-obvious trap.

- **Bare `python` / `python3` / `pip` are denied globally:** Always invoke Python scripts via `uv run --no-project ...` and cached CLI tools (`ruff`, `zensical`) via `uvx --offline ...`.
- **Rust 2024 formatting in OpenCode:** OpenCode's `formatter: true` runs `rustfmt <file>` without Cargo metadata; root `rustfmt.toml` (`edition = "2024"`, `style_edition = "2024"`) keeps single-file `rustfmt` 100% identical to `cargo fmt --all -- --check`.
- **`/tmp` is a 32 GiB RAM `tmpfs` (no XFS `FICLONE`!):** Never place git worktrees, CoW snapshots, PostgreSQL `PGDATA`, or Cargo scratch dirs under `/tmp` — `tmpfs` eats RAM and returns `EOPNOTSUPP` (`95`) on `ioctl(FICLONE)`. Root `/` and `/home/remy` are on an 800 GiB XFS volume (`/dev/mapper/chulak-incus`) with native `reflink=1` CoW support; keep worktrees in `.worktrees/` and CoW state under `~/.cache/slipfork` or `.slipfork/`.
- **`unshare -Urn` (`CLONE_NEWUSER | CLONE_NEWNET`) maps UID 0 -> host `$UID`:** Inside `unshare -Urnpf --mount-proc`, processes see `uid=0` (allowing `ip link set lo up` and PostgreSQL socket binds without `initdb` complaining about root if run via mapped user or unprivileged `unshare -Un` where UID stays `$UID`? Wait: PostgreSQL `initdb`/`postgres` refuses `geteuid() == 0`! Run `unshare --user --keep-caps` or map host `$UID -> $UID` via `/proc/self/uid_map` `"$UID $UID 1"`!). **Verified fact:** Writing `"$UID $UID 1"` to `/proc/self/uid_map` (after `"deny"` to `setgroups` and `"$GID $GID 1"` to `gid_map`) keeps `geteuid() == $UID` (so `postgres` and `initdb` run happily!) WHILE still granting `CAP_NET_ADMIN` inside the userns so `ioctl(SIOCSIFFLAGS)` / `ip link set lo up` brings up isolated `127.0.0.1`!
- **Parent `~/offworld-nexus/opencode.json` MCP inheritance:** Any repo under `~/offworld-nexus/` inherits `fastmail`, `linear-offworld`, `docs`, `sheets`, and `slides` MCP servers unless `.opencode/opencode.jsonc` explicitly overrides them with `"disabled": true`.
- **Single-writer path locks & explicit `git add`:** Never run two active tasks with overlapping `paths` (`tools/plan.py` enforces this mechanically), and always stage explicit file lists (`git add -- <files>`), never `git add .`.
