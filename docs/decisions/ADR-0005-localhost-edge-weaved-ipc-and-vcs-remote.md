# ADR-0005: Single-Origin World Invariant (`WorldOrigin`), Port-80 `*.localhost` Edge (`slipforkd`), Tunnel Weaver Leases (`weaved`), and `VcsWorkspace`

- **Status:** Accepted — amended at `0.1.0` release gate (normative specification for single-origin worlds, sole shared ingress via `slipforkd`, OSPP precedence, `.localhost` routing & `308`/`421` rules, `ProjectSlug` / `WorldTarget` invariants, `TunnelLease` lifecycle, and `VcsWorkspace`; `H-005`, `H-006`, & `H-008` validated)
- **Date:** 2026-11-15

## Context

1. **Dual local + tunnel URLs corrupt stateful web apps:** Exposing both `http://<fork>.<project>.localhost` and a public tunnel URL simultaneously splits `BASE_URL`, `CSRF_TRUSTED_ORIGINS`, cookie domains, OAuth callbacks, S3 presigned URLs, and absolute links in outbound emails — and baking any origin into a reusable fixture snapshot leaks stale URLs into subsequent forks and test slots.
2. **Offline-proof loopback routing & loop-free shared ingress:** RFC 6761 reserves `*.localhost` for loopback (`127.0.0.1` / `::1`) natively in Linux and browser Secure Contexts without external DNS or custom CAs, while optional public sharing via **Tunnel Weaver (`weaved`)** must route into isolated world network namespaces through `slipforkd` without redirect loops, external crate linking, or orphaned leases.
3. **Zero-`cd` agent workspaces (`git` + `jj`):** Developers need `slipfork shell [<fork>]` plus `git pull slipfork <fork>` and `git fetch slipfork <fork>/wip` across both Git worktrees and Jujutsu (`jj`) workspaces without mutating live working trees.

## Decision

> This ADR is the single normative home for the single-origin invariant, `slipforkd` shared ingress (`H-008`), OSPP precedence, `.localhost` routing, and `308`/`421` edge rules (§1), `TunnelLease` daemon lifecycle & `WeavedRegistrar` gating (§2), and canonical VCS `ProjectSlug` discovery + `VcsWorkspace` (§3). `ARCHITECTURE.md` keeps only concise Rust port signatures, and `docs/design/target-dx.md` keeps only user-facing CLI examples.

1. **Single Canonical Origin Invariant (`WorldOrigin`), OSPP Precedence, and `slipforkd` Edge Ingress (`H-008`):**
   - **Single-Origin Invariant (normative):** A world has **at most one public origin**: `WorldOrigin = Local { url } | Shared { url }` (`crates/slipfork-world`, M2) — **never both, never two**, ratifying the owner's release-gate directive: *"a given environment is going to be either shared either not shared but will have at most one URL (and if you hit the local URL of a shared one you're just sent to the shared URL)"* (`H-008`). World cards and `slipfork list` MUST print **exactly one URL per world** (`origin.url()`), and `StaticUrl`/S3 signing, email absolute links, and OAuth callbacks all derive from that single origin. `LocalHostRoute::url()` / `ResourceCoordinates::local_for_world` is the **sole constructor** of `WorldOrigin::Local { url }` (M2 adds no parallel renderer).
   - **Boot-Time Origin Assignment & Per-World DAG Split (normative):** `WorldOrigin` is known before and assigned at **world materialization**, never sealed into a reusable snapshot. `${{ resources::app.url }}`, `${{ domains::<id> }}`, `BASE_URL`, `CSRF_TRUSTED_ORIGINS`, cookie domain, OAuth redirect URIs, email absolute links, `AWS_S3_CUSTOM_DOMAIN`, and any `django.contrib.sites` / Wagtail `Site.root_url` row are **per-world values resolved at boot** and MUST NOT be baked into an origin-independent (`per_world = false`) `[fixtures.<id>]` snapshot (`ADR-0003` §1); fixtures that persist absolute URLs MUST set `per_world = true` so they never share across worlds and run only after `WorldOrigin` assignment. Per the "no stringly plumbing" law (`ADR-0006` §1), `modes.local` MUST NOT carry a hardcoded `BASE_URL`-style literal — Slipfork supplies the resolved origin at boot.
   - **Origin Is Not an OSPP Value & Precedence Rule (normative):**
     - `WorldOrigin` is **NOT** an OSPP (`ADR-0001`) value: OSPP supplies `vars` and `secrets` from a remote control plane, whereas `WorldOrigin` is a property of the live *world instance* (`(ProjectSlug, WorldTarget, Local | Shared)`), known only to Slipfork at materialization time.
     - For a local world, the Slipfork-assigned origin **always wins** over any provider-supplied `domains::` value; a provider bundle MUST NEVER introduce a second reachable origin. In a `Local` world, `${{ domains::<id> }}` resolves strictly to `<id>.(<fork>.)?<project>.localhost` derived from `(ProjectSlug, WorldTarget, id)` via `LocalHostRoute`. In a `Shared` world, referencing `${{ domains::<id> }}` fails closed because only one shared tunnel origin exists. `domains` remains in the `OSPP v1` wire schema strictly for `cloud` deployments.
     - **M2 Dependency Rule (normative):** **OSPP is not a prerequisite for M2 (or M3).** M2 starts and runs end-to-end with `FileVaultProvider` (`0600` local vault) alone and derived `.localhost` origins; `OsppHttpProvider` is an independent later M2 leaf (team/cloud parity), and server-side OSPP work lives in the external provider, never blocking `slipforkd`, `up`, `shell`, or tunnel sharing.
   - **Sole Shared Ingress (`slipforkd`), Planned Static Port & Host Dispatch (`H-008`, `H-006`, normative):**
     - `slipforkd` binds `127.0.0.1:80` and `[::1]:80` (failing closed in `slipfork doctor` / `slipfork up` if unavailable) and acts as the **sole ingress for both `Local` and `Shared` worlds** (`H-008`).
     - **Planned Static Forward Port (`H-008` & `H-006`):** When minting a shared origin, `WorldRegistry` passes a **planned static port owned and proxied by `slipforkd`** (decided before world materialization, never a live world port) in `TunnelRequest.local_port`; `weaved` forwards the shared hostname to `slipforkd`'s planned port, **never** to `*.localhost:80` (which would redirect-loop) and **never** directly into a world netns. `WorldOrigin::Shared { url }` is minted from `TunnelLease::public_url()` **before** materialization so `WorldSpec.base_env` and `per_world = true` seeds receive the final origin on first boot with zero two-origin window (two-phase `Local -> Shared` boot is rejected, `H-008`). `WorldRegistry` owns a `shared_hosts: BTreeMap<String, (ProjectSlug, WorldTarget)>` map populated by `share_world` and cleared by `unshare_world`, `release_world`, or lease drop. Concrete `weaved` registration wire framing remains deferred until `tunnel-weaver` publishes `weaved`'s IPC spec (`H-006`).
     - **Shared-Hostname Dispatch (proxied, never redirected):** Requests matching `WorldRegistry`'s `shared_hosts` map are proxied directly into the world's default ingress via `WorldEngine::dial_world_tcp(&world, port)` with `Host` and `X-Forwarded-*` preserved (HTTP and WebSocket `Upgrade` alike).
     - **`*.localhost` Routing & Disjoint Rule Table (`LocalHostRoute`):** Requests with `*.localhost` `Host` headers follow **`http://(<snow-domain>.)?(<fork>.)?<project>.localhost`**, parsed by `slipfork_world::LocalHostRoute::parse(project: &ProjectSlug, snow_domains: &[&str], host_header: &str)` (`404` on unknown targets):
       - `<project>.localhost` (`0` prefix labels) -> `WorldTarget::Canonical`, `snow_domain: None`.
       - `<domain>.<project>.localhost` (`<domain> ∈ domains[].id`) -> `WorldTarget::Canonical`, `snow_domain: Some(<domain>)`.
       - `<fork>.<project>.localhost` (`<fork> ∉ domains[].id`) -> `WorldTarget::TestSlot(slot)` for `test-<u32>` or `WorldTarget::UserFork(<fork>)`, `snow_domain: None`.
       - `<domain>.<fork>.<project>.localhost` (`<domain> ∈ domains[].id`) -> `WorldTarget::TestSlot(slot)` or `WorldTarget::UserFork(<fork>)`, `snow_domain: Some(<domain>)`.
       - Fork names and `domains[].id` MUST be single lowercase DNS labels (`[a-z0-9-]`, zero dots) and MUST NOT start with `test-`; fork names MUST NOT equal any `domains[].id` (`WorldTarget::validate` + `validate_fork_name` -> `WorldError`, failing closed on malformed `test-*`, `domain.domain` collisions, IPv6 literals, and invalid ports).
     - **Normative `*.localhost` Behaviour by Target World Origin (`H-008`):**
       - **Target world is `WorldOrigin::Local`:** `slipforkd` proxies HTTP and WebSocket traffic via `WorldEngine::dial_world_tcp(&world, port)`.
       - **Target world is `WorldOrigin::Shared { url }` (scoped strictly to `*.localhost` Hosts):**
         1. Every non-upgrade HTTP request on `http://<anything>.<project>.localhost[:80]` resolving to that world — **including `snow_domain` ingresses such as `admin.<project>.localhost` or `admin.<fork>.<project>.localhost`, which collapse into the single shared origin because domain-disjoint routing exists only for `Local` worlds** — MUST be answered with **`308 Permanent Redirect`** (`Location: <shared_url><path_and_query>`) for **every HTTP method** (method + body preserved per RFC 9110 §15.4.9; if `Expect: 100-continue` is present, `slipforkd` MUST send `308 Permanent Redirect` immediately **before** sending `100 Continue` or reading the request body).
         2. Every HTTP `Upgrade` / WebSocket request (`Connection: Upgrade`) on `http://<anything>.<project>.localhost[:80]` resolving to that world MUST be **refused closed with HTTP `421 Misdirected Request`** and an actionable diagnostic body naming `Shared { url }`.
2. **Sharing Fixed at Materialization, Daemon-Owned `TunnelLease`, and Gated `WeavedRegistrar` (`slipfork-world` + `slipfork-edge`):**
   - **Sharing Is Fixed at Materialization (normative):** `slipfork share` and `slipfork share --stop` MUST NOT mutate a live world's origin in place, because already-started processes inside the world would retain stale `BASE_URL`, `CSRF_TRUSTED_ORIGINS`, cookie, and OAuth environment values. Toggling sharedness on an existing world tears down the running world instance, updates the `TunnelLease` (registered against `slipforkd`'s planned static port) and `shared_hosts` map in `WorldRegistry`, and materializes a fresh world from its origin-independent snapshot (`+ per_world` seeds) with the single new `WorldOrigin` injected at boot.
   - **Pure `TunnelRegistrar` Port & Daemon Ownership (`H-006`, `H-008`):** `crates/slipfork-world` defines OS-free `TunnelRegistrar::register(&TunnelRequest { route: &LocalHostRoute, local_port }) -> Result<Box<dyn TunnelLease>, TunnelError>` (`route.snow_domain()` MUST be `None`) and opaque RAII `TunnelLease` (`public_url()`, `lease_id()`). Only `slipfork_edge::WorldRegistry` holds `Arc<dyn TunnelRegistrar>` and manages world/lease lifecycles through `DaemonControl` (`register_world`, `release_world`, `share_world`, `unshare_world`); CLI invocations hold zero leases, while `--stop`, `drop`, `down`, or daemon exit drops the lease and revokes the tunnel. Every `TunnelRegistrar` must pass `assert_tunnel_registrar_conformance`.
3. **Canonical VCS `ProjectSlug` Discovery (`0.1.0`), `slipfork shell [<fork>]`, `git-remote-slipfork`, and `trait VcsWorkspace` (`Git` + `Jujutsu`):**
   - **Canonical VCS root & `ProjectSlug` precedence (`H-005`):**
     - **Git (`git rev-parse`):** Uses `git rev-parse --show-toplevel` as the authoritative worktree root (**never** deriving a repository root or slug from `--git-common-dir` basename). Linked `.worktrees/<fork>` checkouts (where `--git-common-dir` basename is `.git` and `<toplevel>/.git` is a file) resolve `<vcs_root>` to `--git-common-dir`'s parent (never probing worktree-local `.worktrees/<fork>/slipfork.toml`). Fails closed for bare repositories, git submodules (`--show-superproject-working-tree` non-empty), and `--separate-git-dir` layouts, naming the detected topology and the `project = "<slug>"` override in `<vcs_root>/slipfork.toml`.
     - **Jujutsu (`0.1.0` `jj root` adapter, before M2 `JjWorkspaceAdapter`):** Invokes `jj root` only when `jj` is on `PATH` (zero `.jj/repo` internal parsing), failing closed with a `project = "<slug>"` hint when `jj` is absent; `.worktrees/<fork>` under `jj` should set `project = "<slug>"` in `slipfork.toml` until M2's `JjWorkspaceAdapter` lands.
     - **Precedence:** Optional `project = "<slug>"` (`Option<ProjectSlug>`) in `<vcs_root>/slipfork.toml` wins; otherwise `<slug>` parses `<vcs_root>`'s directory basename (`WorldError::InvalidProjectSlug` on invalid DNS labels, failing closed outside any repository).
   - **M2 Interactive Shells & `VcsWorkspace`:** `slipfork shell [<fork>]` enters `<fork>`'s mounted workspace and isolated CoW world. `VcsWorkspaceFactory` wires `GitWorktreeAdapter` (`.worktrees/<fork>` + disk-backed scratch `GIT_INDEX_FILE` synthesizing `<fork>/wip`) or `JjWorkspaceAdapter` (`jj workspace add/forget`, exporting `@` as `<fork>/wip` and `@-` as `<fork>`), registered as `slipfork::.` for `git-remote-slipfork` and verified against shared `assert_vcs_workspace_conformance`.

## Consequences

- Every world has at most one canonical origin known before boot — with `slipforkd` serving as the sole loop-free ingress for both `.localhost` and shared tunnel hostnames — eliminating split-brain cookies/CSRF/OAuth URLs, baked-in snapshot URL leaks, and OSPP startup coupling.
